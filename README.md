# Расчёт теплоты на нагрев технологической среды (Вариант 3)

Модульное консольное приложение на Python.

## Требования
- Python 3.10+ (используется `match-case`)
- VS Code с расширением Python

## Запуск
- **VS Code:** откройте папку проекта — программа запустится автоматически (`.vscode/tasks.json`), либо нажмите **F5**.
- **Терминал:** `python main.py`

> При первом открытии папки VS Code спросит разрешение на автоматические задачи: «Allow Automatic Tasks in Folder» → **Allow**. Или: `Ctrl+Shift+P` → *Tasks: Manage Automatic Tasks* → *Allow Automatic Tasks*.

## Тесты
`python -m unittest tests -v`

## Формула
Q = m · c · (t2 − t1), Дж

## Среды
| Пункт | Среда | c, Дж/(кг·°C) |
|-------|-------|---------------|
| 1 | вода | 4200 |
| 2 | масло | 2000 |
| 3 | сталь | 500 |
| 0 | выход | — |

## Допустимые диапазоны
| Величина | Диапазон |
|----------|----------|
| масса m, кг | 0.1 .. 1000 |
| начальная t1, °C | −50 .. 100 |
| конечная t2, °C | 0 .. 1000, при этом t2 > t1 |

## Классификация нагрева (Δt = t2 − t1)
- Δt < 10 — малый нагрев
- 10 ≤ Δt ≤ 100 — нормальный нагрев
- Δt > 100 — интенсивный нагрев

## Файлы
| Файл | Назначение |
|------|------------|
| main.py | точка входа, главный цикл |

| tests.py | unittest-тесты |
| .vscode/launch.json | запуск по F5 |
| .vscode/tasks.json | автозапуск при открытии папки |
